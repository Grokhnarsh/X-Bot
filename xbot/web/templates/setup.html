Woher kommen diese Werte?

Im X Developer Portal, in dieser Reihenfolge:

  1. Projekt und App anlegen.
  2. User authentication settings → App permissions auf Read and write, Type of App auf Web App, Automated App or Bot.
  3. Erst danach unter Keys and tokens alle Werte erzeugen.
  4. Die Hashtag-Suche braucht mindestens die Zugriffsstufe Basic. Auf der Free-Stufe kann der Bot nur eigene Beiträge veröffentlichen.

Und der Discord-Token?

Im Discord Developer Portal, in dieser Reihenfolge:

  1. New Application anlegen, dann links auf Bot.
  2. Reset Token drücken und den Wert oben als DISCORD_BOT_TOKEN eintragen. Er wird nur einmal angezeigt.
  3. Auf derselben Seite MESSAGE CONTENT INTENT einschalten - ohne dieses Recht liefert Discord nur leere Nachrichten, und der Bot kann auf nichts reagieren.
  4. Unter OAuth2 → URL Generator den Scope bot wählen und die Rechte View Channels, Read Message History, Send Messages und Add Reactions vergeben. Mit der erzeugten Einladungs-URL den Bot auf den Server holen.
  5. Kanal-IDs: in Discord unter Einstellungen → Erweitert den Entwicklermodus einschalten, dann Rechtsklick auf einen Kanal → Kanal-ID kopieren. Sie gehören in die Einstellungen.
